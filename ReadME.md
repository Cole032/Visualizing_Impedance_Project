Visualizing acoustic impedance Final project in Computational physics

This experiment uses a classic impedance tube set-up. 
The pressure is measured at each location, and the Transfer function defined in Utsunos's 1984 paper is used to calculate the impedance and propagation constant. 
The goal of this project is to use the propagation constant and characterstic impedance to better visualize based on the data what is happening within the impedancetube.
